# PMP Trainer — تطبيق تدريب PWA لأسئلة PMP

تطبيق ويب تقدمي (PWA) للتدريب على أسئلة اختيار من متعدد لامتحان PMP، مقسم حسب الفصل ومستوى الصعوبة، يعمل بدون إنترنت بعد أول تحميل، ويحفظ تقدمك محلياً بالمتصفح.

## 1. التشغيل محلياً

```bash
npm install
npm run dev
```

افتح `http://localhost:3000` بالمتصفح.

## 2. تحديث بنك الأسئلة (الأهم بالنسبة لك)

كل الأسئلة موجودة بملف واحد: `data/questions.json`.

### هيكلية الملف

```json
{
  "chapters": [
    {
      "id": "ch01",
      "title": "الفصل 1: اسم الفصل",
      "questions": [
        {
          "id": "ch01-q001",
          "level": "easy",
          "question": "نص السؤال",
          "options": ["خيار 1", "خيار 2", "خيار 3", "خيار 4"],
          "correctIndex": 0,
          "explanation": "شرح ليش هذا الخيار هو الصحيح"
        }
      ]
    }
  ]
}
```

### كيف تضيف أسئلة جديدة

1. اطلب مني (Claude) أسئلة جديدة على شكل JSON بنفس الهيكلية أعلاه — إما فصل كامل جديد، أو أسئلة إضافية لفصل موجود.
2. افتح `data/questions.json`.
3. إذا الفصل موجود: أضف كائنات الأسئلة الجديدة داخل مصفوفة `questions` تبعه.
4. إذا فصل جديد: أضف كائن فصل جديد كامل داخل مصفوفة `chapters`.
5. **مهم جداً:** كل `id` لازم يكون فريد ما يتكرر بكل الملف (سؤال أو فصل).
6. احفظ الملف، اعمل `git commit` و `git push` — Vercel رح يبني وينشر النسخة الجديدة تلقائياً خلال دقيقة أو دقيقتين، بدون أي تعديل على الكود.

القيم المسموحة لـ `level`: `easy` (سهل) / `medium` (متوسط) / `hard` (صعب).

## 3. الربط مع GitHub

```bash
git init
git add .
git commit -m "بداية مشروع PMP Trainer"
git branch -M main
git remote add origin https://github.com/USERNAME/pmp-trainer.git
git push -u origin main
```

غيّر `USERNAME` باسم حسابك، وأنشئ الـ repo فاضي على GitHub قبل هذا (بدون README حتى ما يصير تعارض).

## 4. النشر على Vercel

1. روح لـ https://vercel.com وسجل دخول بحساب GitHub.
2. اضغط "Add New Project" واختر الـ repo تبع المشروع.
3. Vercel رح يتعرف تلقائياً إنه مشروع Next.js، خليك على الإعدادات الافتراضية واضغط Deploy.
4. بعد أول نشر، أي `git push` جديد على `main` رح ينشر نسخة محدثة تلقائياً — هيك رح تحدث الأسئلة بدون ما تلمس الكود أو تعيد بناء شي يدوياً.

## 5. تثبيت التطبيق كـ PWA على الهاتف

**Android (Chrome):**
افتح رابط التطبيق على Vercel، اضغط قائمة الثلاث نقاط، اختر "Add to Home screen" / "تثبيت التطبيق".

**iPhone (Safari):**
افتح الرابط، اضغط أيقونة المشاركة (Share)، اختر "Add to Home Screen".

بعد التثبيت رح يشتغل التطبيق متل أي تطبيق عادي، وتقدر تفتح الأسئلة اللي سبق حملتها حتى بدون إنترنت.

## 6. أيقونات التطبيق

لازم تضيف صورتين بمجلد `public/icons/`:
- `icon-192.png` (192×192 بكسل)
- `icon-512.png` (512×512 بكسل)

استخدم أي شعار بسيط أو لوغو، وأي أداة تحويل صور أونلاين لعمل الأحجام المطلوبة.

## 7. بنية المشروع

```
pmp-pwa/
├── app/
│   ├── layout.js        # التخطيط العام + تسجيل Service Worker
│   ├── page.js           # الرئيسية: اختيار الفصل والمستوى
│   ├── globals.css
│   ├── quiz/page.js      # صفحة التدريب على فصل ومستوى محددين
│   ├── mock-exam/page.js # الاختبار التجريبي المؤقت
│   └── stats/page.js     # لوحة الإحصائيات والتقدم
├── components/
│   └── QuestionCard.js   # مكون عرض السؤال مع التغذية الراجعة الفورية
├── lib/
│   ├── questions.js      # قراءة وفلترة بنك الأسئلة
│   └── storage.js        # حفظ التقدم بـ localStorage
├── data/
│   └── questions.json    # بنك الأسئلة — هذا الملف اللي بتحدثه باستمرار
├── public/
│   ├── manifest.json     # إعدادات PWA
│   └── service-worker.js # العمل بدون إنترنت
├── package.json
├── next.config.js
├── tailwind.config.js
└── jsconfig.json
```
